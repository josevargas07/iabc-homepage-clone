
# IABC Homepage Clone

A responsive recreation of the International Association of Business Communicators (IABC) homepage built with **pure HTML and CSS** (no JavaScript, no frameworks).

**[Live Demo](https://josevargas07.github.io/iabc-homepage-clone/)**

![IABC Homepage Clone Screenshot](https://raw.githubusercontent.com/josevargas07/iabc-homepage-clone/main/screenshot.png)

## What I practiced

- **CSS Grid** for organizing the main content into a responsive two-column layout featuring the Gold Quill Awards banner and news section.
- **Flexbox** for aligning the logo, social media icons, and navigation links in the header.
- **Hover effects** for highlighting navigation links when hovering over them.
- **Responsive design** using media queries to adapt the layout to different screen sizes.
- **Semantic HTML** using elements such as `header`, `nav`, `main`, `section`, `aside`, and `footer`.
- **HTML accessibility basics**, including descriptive image alt text, accessible labels, and keyboard focus styles.
- **External links** to social media platforms using `target="_blank"` and `rel="noopener noreferrer"`.
- **CSS variables** for maintaining consistent colors throughout the website.
- **CSS organization** by separating styles into individual files for different page components.

## Run locally

Clone the repository:

```bash
git clone https://github.com/josevargas07/iabc-homepage-clone.git
```

Open `index.html` in your browser or use the Live Server extension in VS Code.
